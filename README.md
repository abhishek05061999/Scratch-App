# Scratch-like Visual Code Editor

A visual code editor similar to MIT Scratch built with React, TypeScript, and TailwindCSS.

## Features

1. Motion Animations:
   - Move steps
   - Turn degrees
   - Go to x, y
   - Repeat animation

2. Looks Animations:
   - Say for seconds
   - Think for seconds

3. Multiple Sprites Support:
   - Create multiple sprites
   - Apply animations to each sprite
   - Play all sprites at once

4. Hero Feature - Collision-Based Animation Swap:
   - When two sprites collide, their animations swap
   - Dynamic interaction between characters

## How to Run

1. Clone the repository
2. Install dependencies: `npm install`
3. Start the development server: `npm start`
4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## How to Use

1. Add blocks from the left panel to the active sprite.
2. Use the "Add Sprite" button to create more sprites.
3. Click "Play All" to run all sprite animations.
4. Create two sprites with opposite move animations to see the collision effect.
